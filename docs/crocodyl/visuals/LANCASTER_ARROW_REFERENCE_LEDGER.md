## Nock families and rear-end interfaces

| Crocodyl taxonomy | Lancaster reference | Retained facts |
| --- | --- | --- |
| Direct-fit / insert nock | Lancaster nock guide; Beiter Insert Nock | Nock stem inserts into shaft/bushing; common fitment classes include .166, .204 and .245 in |
| Pin nock | Easton Pin Nock / Beiter Pin Nock | Fits a separate rear pin/bushing; Beiter small groove .088 in and large groove .098 in |
| Pin-out / over-shaft nock | Beiter Pin-Out Nock | Fits on the pin while extending over the end of the shaft |
| Bushing-backed insert nock | X7 Eclipse / Platinum Plus | UNI/G-UNI/Super-UNI-style rear bushing is installed in shaft, nock interfaces with the bushing |
| Rear impact collar | Easton X10 3.2 mm Nock Impact Collar | Protects rear shaft from impact/cracking; 3 gr; compatible only with listed shaft families |
| Conventional tapered/swaged rear | Easton XX75 Tribute | Precision-ground nock swage and conventional nock compatibility |

Lancaster's 2026 nock guide records examples such as Easton N throat 0.100 in/groove 0.081 in with .166 fitment, Easton G Pin throat 0.113 in/groove 0.099 in, Easton Pin Small throat 0.099 in/groove 0.084 in, and Easton Pin Large throat 0.111 in/groove 0.096 in. These are interface examples, not universal dimensions.

## Modelling rules

1. `published` means directly stated by Lancaster/manufacturer data on the Lancaster page.
2. `photo-observed` means a visible relationship in product photography, not a measurement.
3. `generic-topology` means the family is real but exact taper length, wall thickness or hidden interface was not published; Crocodyl must not label that mesh as an exact product replica.
4. Brand names appear only in provenance/reference metadata. User-facing generic taxonomy meshes remain unbranded.
5. Compatibility is never inferred from diameter alone. Preserve explicit product-family compatibility notes.
6. Lancaster photographs are references only and are not committed, embedded, traced as textures, or redistributed.
